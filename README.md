## ATB Side View Battle System용 추천 스탯 구조

ATB **Wait 방식**에서는 플레이어가 명령을 선택하는 동안 전투가 멈추기 때문에, 민첩 스탯은 조작 속도보다 **행동 순서, 게이지 충전, 재행동 속도**에 영향을 주도록 설계하는 것이 좋습니다.

---

### 1. 기본 능력치

| 스탯      | 명칭 | 주요 효과                       |
| ------- | -- | --------------------------- |
| **STR** | 힘  | 물리 공격력, 일부 무기 스킬 위력         |
| **VIT** | 체력 | 최대 HP, 물리 방어력               |
| **INT** | 지능 | 마법 공격력, 공격 마법 위력            |
| **MND** | 정신 | 마법 방어력, 회복 마법 위력            |
| **DEX** | 기술 | 명중률, 치명타율, 일부 스킬 성공률        |
| **AGI** | 민첩 | ATB 충전 속도, 회피율, 행동 후 대기시간   |
| **LUK** | 행운 | 상태이상 성공·저항, 치명타 보정, 아이템 획득률 |

이 정도면 전사, 도적, 마법사, 사제, 탱커 등의 역할을 모두 구분할 수 있습니다.

---

### 2. 자원 스탯

| 스탯      | 용도                     |
| ------- | ---------------------- |
| **HP**  | 생명력. 0이 되면 전투 불능       |
| **MP**  | 마법 및 특수 스킬 사용          |
| **ATB** | 행동 가능 여부를 결정하는 실시간 게이지 |

---

### 3. 전투용 파생 스탯

플레이어에게는 아래 스탯들을 장비 화면에 표시하는 것을 추천합니다.

| 스탯             | 계산에 사용하는 능력치   | 설명        |
| -------------- | -------------- | --------- |
| **ATK**        | STR + 무기 공격력   | 물리 피해량    |
| **DEF**        | VIT + 방어구 방어력  | 물리 피해 감소  |
| **MATK**       | INT + 무기 마법 공격력 | 마법 피해량    |
| **MDEF**       | MND + 방어구 마법 방어력 | 마법 피해 감소  |
| **HIT**        | DEX            | 공격 명중률    |
| **EVA**        | AGI            | 공격 회피율    |
| **CRIT**       | DEX + LUK      | 치명타 발생률   |
| **CRIT DMG**   | 무기·패시브         | 치명타 피해 배율 |
| **STATUS HIT** | DEX + LUK      | 상태이상 성공률  |
| **STATUS RES** | MND + LUK      | 상태이상 저항률  |

---

### 4. 추천 기본 계산식

#### 최대 HP

```text
최대 HP = 직업 기본 HP + VIT × 15 + 레벨 × 직업 HP 성장치
```

#### 최대 MP

```text
최대 MP = 직업 기본 MP + INT × 3 + MND × 5
```

마법사는 INT가 높고, 사제는 MND가 높아도 충분한 MP를 확보할 수 있습니다.

#### 물리 공격력

```text
ATK = 무기 공격력 + STR × 2
```

#### 물리 방어력

```text
DEF = 방어구 방어력 + VIT × 1.5
```

#### 마법 공격력

```text
MATK = 무기 마법 공격력 + INT × 2
```

#### 마법 방어력

```text
MDEF = 방어구 마법 방어력 + MND × 1.5
```

---

### 5. ATB 게이지 공식

AGI가 높을수록 ATB 게이지가 빠르게 채워지도록 합니다.

```text
ATB 충전 시간 = 기본 충전 시간 × 100 ÷ (100 + AGI)
```

기본 충전 시간을 8초로 설정했을 때:

| AGI | ATB 충전 시간 |
| --: | --------: |
|  10 |   약 7.27초 |
|  30 |   약 6.15초 |
|  50 |   약 5.33초 |
|  80 |   약 4.44초 |
| 100 |      약 4초 |

AGI가 지나치게 높아졌을 때 밸런스가 무너지지 않도록 최종 충전 시간은 최소 2.5~3초 정도로 제한하는 것이 좋습니다.

```text
최종 ATB 시간 = Max(3초, 계산된 ATB 시간)
```

---

### 6. 스킬별 행동 지연

모든 스킬을 사용한 뒤 동일하게 ATB가 초기화되면 빠른 공격과 강한 공격의 차이가 부족해집니다. 스킬마다 행동 지연 배율을 넣는 것이 좋습니다.

| 스킬 종류  | 행동 지연 배율 |
| ------ | -------: |
| 빠른 공격  |      0.7 |
| 일반 공격  |      1.0 |
| 일반 스킬  |      1.1 |
| 강력한 스킬 |      1.3 |
| 전체 공격  |      1.5 |
| 궁극기    |      1.7 |

```text
다음 ATB 충전 시간
= 기본 ATB 충전 시간 × 스킬 행동 지연 배율
```

예를 들어 일반 ATB 충전 시간이 5초인 캐릭터가 전체 공격을 사용하면:

```text
5초 × 1.5 = 7.5초
```

다음 행동까지 7.5초가 걸립니다.

---

### 7. 캐스팅 스탯

마법이나 강력한 기술은 ATB가 찬 뒤 바로 발동하지 않고 캐스팅을 거치도록 만들 수 있습니다.

```text
최종 캐스팅 시간
= 기본 캐스팅 시간 × 100 ÷ (100 + DEX × 0.5 + AGI × 0.25)
```

DEX는 주문이나 기술을 정확하게 준비하는 능력, AGI는 행동 속도를 의미합니다.

캐스팅 중에는 다음 효과를 적용할 수 있습니다.

* 피해를 받으면 캐스팅 지연
* 특정 공격에 맞으면 캐스팅 취소
* 침묵 상태에서는 마법 캐스팅 불가
* 가속 버프를 받으면 캐스팅 시간 감소

캐스팅 시간 감소는 최대 50% 정도로 제한하는 편이 안전합니다.

---

### 8. 명중과 회피

```text
기본 명중률 = 95 + 공격자 DEX × 0.1
회피율 = 방어자 AGI × 0.08 + 장비 회피율
최종 명중률 = 기본 명중률 - 회피율
```

최종 명중률 제한:

```text
최소 20%
최대 100%
```

보스나 주요 스킬에는 별도의 명중 보정을 줄 수 있습니다.

```text
일반 공격 명중 보정: 0%
정밀 공격 명중 보정: +20%
강력한 공격 명중 보정: -10%
마법 명중 보정: +10%
```

---

### 9. 치명타

```text
치명타 확률
= 기본 5% + DEX × 0.05% + LUK × 0.03% + 장비 보정
```

```text
치명타 피해 = 기본 피해 × 1.5
```

추천 제한:

```text
치명타 확률 최대 50%
기본 치명타 피해 150%
치명타 피해 최대 250%
```

도적이나 궁수는 패시브와 장비를 통해 치명타 특화가 가능하도록 하면 됩니다.

---

### 10. 상태이상 관련 스탯

상태이상 성공률은 스킬 자체 확률과 공격자·방어자의 능력치를 함께 계산합니다.

```text
최종 상태이상 확률
= 스킬 기본 확률
× (100 + 공격자 DEX + 공격자 LUK)
÷ (100 + 방어자 MND + 방어자 LUK)
```

예시 상태이상:

| 상태이상  | 효과                |
| ----- | ----------------- |
| 독     | 일정 시간마다 HP 감소     |
| 화상    | 지속 피해 및 물리 공격력 감소 |
| 출혈    | 행동할 때마다 피해        |
| 침묵    | 마법 사용 불가          |
| 실명    | 명중률 감소            |
| 둔화    | ATB 충전 속도 감소      |
| 가속    | ATB 충전 속도 증가      |
| 기절    | ATB 정지 및 행동 불가    |
| 수면    | 행동 불가, 피해를 받으면 해제 |
| 혼란    | 임의 대상을 공격         |
| 도발    | 특정 적만 공격          |
| 방어 파괴 | DEF 감소            |
| 마법 공격력 파괴 | MATK 감소           |

ATB 시스템에서는 **둔화, 가속, 기절, 캐스팅 방해**가 특히 중요한 상태이상입니다.

### 11. 속성 스탯

추천 속성은 너무 많지 않게 6~8개 정도가 적절합니다.

```text
물리
화염
냉기
번개
대지
바람
빛
어둠
```

속성 저항은 퍼센트로 관리합니다.

|  저항값 | 결과            |
| ---: | ------------- |
| -50% | 150% 피해       |
|   0% | 100% 피해       |
|  25% | 75% 피해        |
|  50% | 50% 피해        |
| 100% | 피해 무효         |
| 120% | 받은 피해의 20% 회복 |

일반 캐릭터의 저항은 최대 75% 정도로 제한하고, 완전 면역은 특정 장비나 보스 전용으로 사용하는 것이 좋습니다.

### 추천 최종 구성

플레이어가 직접 성장시키는 능력치는 아래 7개가 적당합니다.

```text
STR 힘
VIT 체력
INT 지능
MND 정신
DEX 기술
AGI 민첩
LUK 행운
```

장비창에 표시할 전투 스탯은 아래처럼 구성하면 됩니다.

```text
HP / MP
ATK / DEF
MATK / MDEF
HIT / EVA
CRIT / CRIT DMG
ATB SPEED
상태이상 적중 / 상태이상 저항
속성 저항
```

이 구조는 **ATB 게이지 속도, 캐스팅, 행동 후 딜레이, 상태이상, 치명타**를 모두 활용할 수 있어서 Wait 방식의 사이드뷰 전투에 잘 맞습니다.
