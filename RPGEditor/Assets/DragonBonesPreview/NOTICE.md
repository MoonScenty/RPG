# DragonBones Preview Runtime

`pixi.min.js`는 [PixiJS](https://github.com/pixijs/pixijs) v5의 WebGL 렌더러이며 MIT 라이선스로 배포됩니다.

`dragonBones.min.js`는 [pixi5-dragonbones](https://github.com/kreezii/pixi5-dragonbones)
(PixiJS v5용 DragonBones 런타임)이며 MIT 라이선스로 배포됩니다.

두 파일 모두 적 캐릭터 탭의 DragonBones 아마추어 선택 다이얼로그에서 실제 스켈레톤 애니메이션
미리보기를 재생하는 데 사용됩니다.
